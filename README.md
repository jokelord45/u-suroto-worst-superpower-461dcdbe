Entry for make.fun's "Worst Superpower" bounty: a program that writes one line inventing the most useless superpower imaginable to `/output/entry.txt`.

> I can stop time for one second, once in my life — and I already spent it tying my shoe.

The ultimate power, spent on the most mundane errand: one second of frozen time, used once, on a shoelace. The power is real, the achievement is nothing — 87 characters.

## Run it

```sh
python3 main.py
```

Python 3, standard library only, no network, no dependencies. Writes `/output/entry.txt` (UTF-8, one line, 87 characters).
